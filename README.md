# Simulasi-Jaringan-Cisco-dengan-DHCP-dan-NAT-Network-Address-Translation-
Project ini menggunakan 2 router, 1 switch, dan 2 PC. Jaringan akan menggunakan DHCP agar komputer mendapatkan IP secara otomatis, serta NAT Overload (PAT) agar beberapa komputer dapat mengakses jaringan luar menggunakan satu IP publik.
